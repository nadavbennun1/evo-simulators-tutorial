04

Run the inverse problem

Bayes updates uncertainty about parameters

The prior assigns plausibility before observing the data. The likelihood evaluates the data under each parameter value. The evidence p(xobs) normalizes their product into the posterior.

p(θ | xobs) =p(xobs | θ) p(θ)p(xobs)
Identifiability
Whether distinct parameter values make distinguishable predictions.
Credible interval
An interval containing a stated fraction of posterior probability, conditional on model and prior.

ABC retains simulations within distance tolerance ε. NPE learns a normalized conditional density from many parameter–trajectory pairs; amortization makes later observations cheap to analyze.

06

Return to biology

A posterior is useful when it predicts and survives checks

A posterior predictive distribution simulates trajectories—or new derived quantities—from posterior draws. A PPC compares these predictions with observations. A collective posterior combines independent replicate evidence while correcting repeated prior factors.

Prediction
Propagate posterior uncertainty through the simulator to a biological quantity.
Model check
Locate systematic disagreements between posterior simulations and data.
