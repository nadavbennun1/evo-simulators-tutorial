From equation to trustworthy code

  1. 1
    Choose state

    Represent mutually exclusive genotype frequencies as a vector that sums to one.

  2. 2
    Transform parameters

    Work in log₁₀ space for small formation rates, then exponentiate inside the simulator.

  3. 3
    Update mechanism

    Apply mutation and relative fitness in a declared order; matrix orientation must match the state vector.

  4. 4
    Sample drift

    For Wright–Fisher dynamics, draw the next finite population rather than only normalizing expectations.

  5. 5
    Observe

    Record only scheduled generations and apply a separate measurement model.

Implementation invariant: after every generation, frequencies are finite, non-negative, and sum to one.

def noisy_sims(simulator, theta, sigma, n=20, extra_kw=None):
    """
    Run `simulator` n times, each with theta perturbed by independent Gaussian noise.

    Each simulation draws  theta_i ~ N(theta, sigma)  and uses a different drift seed.
    The spread of the resulting trajectories reflects BOTH parameter variation across
    replicates AND within-replicate stochastic drift.

    Parameters
    ──────────
    simulator : callable  — the WF/ODE simulator function
    theta     : dict      — central parameter values  (tune to match data)
    sigma     : dict      — per-parameter noise std   (tune to match data spread)
    n         : int       — number of simulations
    extra_kw  : dict      — additional fixed kwargs (e.g. generation=...) not perturbed

    Returns: list of n simulation results
    """
    extra_kw = extra_kw or {}
    results  = []
    for i in range(n):
        rng = np.random.default_rng(i)
        theta_i = {k: v + rng.normal(0, sigma.get(k, 0)) for k, v in theta.items()}
        np.random.seed(i)
        results.append(simulator(**theta_i, **extra_kw))
    return results

def WF_Avecilla(log_delta_C, log_delta_B, s_C, s_B,
                generation, seed=None, N=int(3.3e8)):
    """
    Avecilla et al. 3-genotype Wright-Fisher simulator.

    Parameters
    ──────────
    log_delta_C : log10(CNV formation rate δ_C per generation)
    log_delta_B : log10(other-beneficial mutation rate δ_B per generation)
    s_C, s_B    : fitness advantages (linear scale)
    generation  : array of generation indices to return
    N           : effective population size (default 3.3 × 10^8)

    Returns: np.ndarray shape (len(generation), 3) — frequencies [x_A, x_C, x_B]
    """
    delta_C = 10 ** log_delta_C
    delta_B = 10 ** log_delta_B

    if seed is not None:
        np.random.seed(seed)

    w = np.array([1.0, 1.0 + s_C, 1.0 + s_B])
    M = np.array([
        [1 - delta_C - delta_B,  0,  0],
        [delta_C,                1,  0],
        [delta_B,                0,  1],
    ], dtype='float64')
    E = M @ np.diag(w)

    n = np.array([N, 0.0, 0.0])
    freqs = []
    for _ in range(int(generation.max()) + 1):
        freqs.append(n / n.sum())
        p = E @ (n / n.sum())
        p /= p.sum()
        n = np.random.multinomial(int(N), p).astype(float)

    return np.array(freqs)[generation.astype(int)]

Diagnostic: does one selection coefficient describe the whole sweep?

The fit above gives every GAP1 CNV the same advantage sC. Real CNVs are not interchangeable — amplicon size, copy number and breakpoint all vary — so each new CNV is better described as drawing its effect from a distribution of fitness effects (DFE).

A DFE leaves a signature in the shape of the trajectory. Selection enriches the CNV pool for its own upper tail, so the mean advantage of the cells carrying a CNV rises with time even though the DFE itself never changes. A model that insists on a single s can only absorb that by reporting a different s in each stretch of the trajectory.

The diagnostic makes that explicit:

  1. Generate under a DFE — replace the single CNV genotype with K classes; a new CNV lands in class k with probability pk and carries fitness 1+sk, mean s¯.
  2. Fit a constant-s WF to sliding windows — in each window of W=30 generations, fit the 2-genotype WF (CNV vs. everything else) with δC held fixed, so s is the only free parameter.
  3. Plot s^ against window midpoint.

Constant-s data should give a flat s^ at the true value; DFE data should give a rising s^. The same fit is applied to the Lauer replicates for comparison.

# ── Step 1: the same WF, but CNVs draw their fitness from a DFE ──────────────
from scipy.stats import gamma as gamma_dist

DFE_SHAPE = 2.0    # gamma shape of the CNV fitness-effect distribution
DFE_SMAX  = 0.10   # sets the scale of the grid (rescaled to hit the mean)
DFE_K     = 25     # number of CNV fitness classes


def dfe_grid(s_bar, shape=DFE_SHAPE, s_max=DFE_SMAX, K=DFE_K):
    """
    Discrete DFE for new CNVs: K fitness classes on (0, s_max], gamma-shaped weights.

    The DFE *is* this grid — weights come from a gamma pdf evaluated on the grid and
    normalised, then the effects are rescaled so the grid mean is exactly `s_bar`
    (no hidden truncation error, and s_bar is comparable to s_C of the constant-s model).

    Returns: (s_grid, p_grid), both length K
    """
    s = np.linspace(s_max / K, s_max, K)
    p = gamma_dist.pdf(s, a=shape, scale=s_bar / shape)
    p /= p.sum()
    return s * (s_bar / (p @ s)), p


def WF_Avecilla_DFE(log_delta_C, log_delta_B, s_bar, s_B,
                    generation, seed=None, N=int(3.3e8), **dfe_kw):
    """
    Avecilla WF in which each new CNV draws its own fitness effect from a DFE.

    Identical to `WF_Avecilla` except that the single CNV genotype X_C is split into
    K classes: the ancestor mutates into class k at rate δ_C·p_k and that class carries
    fitness 1 + s_k.  Mutation → selection → multinomial drift are unchanged, and
    s_bar plays the role of s_C on average.

    Parameters
    ──────────
    log_delta_C, log_delta_B, s_B : as in WF_Avecilla
    s_bar       : mean of the CNV fitness-effect distribution
    dfe_kw      : passed to dfe_grid (shape, s_max, K)

    Returns: np.ndarray shape (len(generation), 4) —
             [x_A, x_C (all classes summed), x_B, mean s among CNV cells]
    """
    s_grid, p_grid = dfe_grid(s_bar, **dfe_kw)
    K = len(s_grid)
    delta_C = 10 ** log_delta_C
    delta_B = 10 ** log_delta_B

    if seed is not None:
        np.random.seed(seed)

    w = np.concatenate([[1.0], 1.0 + s_grid, [1.0 + s_B]])
    M = np.zeros((K + 2, K + 2))
    M[0, 0]           = 1 - delta_C - delta_B
    M[1:K + 1, 0]     = delta_C * p_grid          # ancestral → CNV class k
    M[K + 1, 0]       = delta_B                   # ancestral → other beneficial
    M[np.arange(1, K + 2), np.arange(1, K + 2)] = 1.0
    E = M @ np.diag(w)

    n = np.zeros(K + 2); n[0] = N
    out = []
    for _ in range(int(generation.max()) + 1):
        x   = n / n.sum()
        x_C = x[1:K + 1].sum()
        out.append([x[0], x_C, x[K + 1],
                    (x[1:K + 1] @ s_grid) / x_C if x_C > 0 else np.nan])
        p = E @ x
        p /= p.sum()
        n = np.random.multinomial(int(N), p).astype(float)

    return np.array(out)[generation.astype(int)]

# ── Step 2: fit a constant-s WF to sliding windows ───────────────────────────
from scipy.optimize import minimize_scalar

WINDOW    = 30           # window width, generations
MIN_PTS   = 3            # time points required inside a window
FIT_LIMIT = (-0.2, 1.0)  # search range for s-hat


def _wf_const_s(s, x0, n_gen, delta_C=0.0):
    """Deterministic constant-s WF, CNV vs. everything else (mutation, then selection)."""
    x, out = float(x0), [float(x0)]
    for _ in range(n_gen):
        x_mut = x + delta_C * (1 - x)
        x = x_mut * (1 + s) / (1 + s * x_mut)
        out.append(x)
    return np.array(out)


def _logit(x, eps=1e-9):
    x = np.clip(np.asarray(x, float), eps, 1 - eps)
    return np.log(x / (1 - x))


def fit_constant_s(gens, freqs, delta_C=0.0):
    """
    Least-squares fit of a constant-s WF to one stretch of a CNV trajectory.

    s is the only free parameter: δ_C is held at its fitted value and the model is
    anchored at the first observed frequency of the window. Residuals are taken on the
    logit scale so a window at 1% CNV and a window at 60% CNV are weighted comparably.
    """
    gens, freqs = np.asarray(gens, float), np.asarray(freqs, float)
    idx = np.round(gens - gens[0]).astype(int)
    y   = _logit(freqs)

    def loss(s):
        pred = _wf_const_s(s, freqs[0], idx[-1], delta_C)[idx]
        return np.sum((_logit(pred) - y) ** 2)

    return minimize_scalar(loss, bounds=FIT_LIMIT, method='bounded').x


def sliding_s_hat(gens, freqs, width=WINDOW, delta_C=0.0, min_pts=MIN_PTS, x_max=0.98):
    """
    Fit a constant-s WF in every window [t, t + width]; return (midpoints, s_hat).

    One window is anchored at each observed time point. Windows with fewer than
    `min_pts` points, or that start above `x_max`, are dropped — once the CNV has swept
    there is no frequency change left to estimate s from.
    """
    gens, freqs = np.asarray(gens, float), np.asarray(freqs, float)
    mids, s_hat = [], []
    for t0 in gens[gens <= gens[-1] - width]:
        m = (gens >= t0) & (gens <= t0 + width)
        if m.sum() < min_pts or freqs[m][0] > x_max or not np.all(np.isfinite(freqs[m])):
            continue
        mids.append(t0 + width / 2)
        s_hat.append(fit_constant_s(gens[m], freqs[m], delta_C))
    return np.array(mids), np.array(s_hat)

  constant-s truth : 0.068 → 0.069   (flat; true s_C = 0.07)

Reading the figure. The left panel is the identifiability problem: a constant s and a DFE with a lower mean produce trajectory envelopes that both cover the data, because the DFE's upper tail compensates for its lower mean. A single fit to the full trajectory cannot separate them.

The right panel does separate them. Fitted to constant-s data, the windowed estimator is flat and lands on the true sC=0.07 — so the rise seen elsewhere is a property of the data, not of the estimator. Fitted to DFE data, s^ climbs steadily and tracks the dashed line: the true mean advantage of the cells that carry a CNV, which rises as selection enriches the pool for its own upper tail. The trend in s^, not its value, is what carries information about the DFE.

On the Lauer replicates, s^ also rises — from ≈ 0 to ≈ 0.11 — but a DFE is only one of several explanations, and this diagnostic does not choose between them:

  • the earliest windows sit on a 1–3% plateau close to the detection floor, where a rise from near-zero s^ is expected whether or not fitness varies (the same plateau motivates the pre-existing CNV⁻ pool in the Chuong model, §3);
  • competing beneficial mutations (XB) and clonal interference bend the trajectory as well;
  • δC is held fixed inside every window, so any error in it is absorbed by s^.

For inference. A rising s^ says the constant-s WF is misspecified for that data, which matters for SBI: the posterior over sC will concentrate on whatever value best compromises across the whole trajectory, with a tightness that reflects the assumed model rather than the actual uncertainty. Either fit the DFE parameters (s¯, shape) directly — WF_Avecilla_DFE is a drop-in simulator — or use the windowed s^ trend as a posterior-predictive check on a fitted constant-s model.

2. Avecilla et al. — Chemostat ODE Model

Why an ODE for chemostat evolution?

In a chemostat, cells grow continuously — not in discrete synchronized generations. The ODE models nutrient-limited growth explicitly via Monod kinetics.

Three genotypes with mutation

dXAdt=XA(μA−D)−(δC+δB)XA
dXCdt=XC(μC−D)+δCXA
dXBdt=XB(μB−D)+δBXA
dSdt=D(S0−S)−1Y(XAμA+XCμC+XBμB)

with Monod kinetics μi=riS/(S+k) and ri=rA(1+siln2).

Parameters (Avecilla et al., Table 2)

Symbol Value Meaning
D 0.12 h⁻¹ Dilution rate
S0 0.8 mM Influent glutamine
k 0.103 mM Half-saturation (all genotypes)
Y 3.24 × 10⁷ cells mL⁻¹ mM⁻¹ Yield
rA 0.166 h⁻¹ Ancestral max growth rate

Time axis: hours. Conversion: 1 WF generation =1.5 h (empirical chemostat value).

# Avecilla et al. Table 2 constants
D_AVE  = 0.12      # h⁻¹  dilution rate
S0_AVE = 0.8       # mM   influent substrate
K_AVE  = 0.103     # mM   half-saturation
Y_AVE  = 3.24e7    # cells/mL/mM  yield
R_A    = 0.166     # h⁻¹  ancestral max growth rate

GEN_TO_HOURS = 1.5   # hours per WF generation (empirical chemostat value)


def WF_Avecilla_ODE(log_delta_C, log_delta_B, s_C, s_B,
                    D=D_AVE, S0=S0_AVE, k=K_AVE, Y=Y_AVE, r_A=R_A,
                    t_max=700.0, n_points=1000):
    """
    Avecilla et al. chemostat ODE — 3 competing genotypes with mutation.

    Parameters use the same WF convention (per-generation s and δ), converted to per-hour:
        delta_per_hr = 10**log_delta / GEN_TO_HOURS
        r_C = r_A * (1 + s_C / (D * GEN_TO_HOURS))   # exact at steady state

    Returns: t_grid (hours), freqs shape (n_points, 3) — [x_A, x_C, x_B]
    """
    # Consistent with WF: at chemostat steady state, per-generation advantage = s_C
    # mu_C - mu_A = s_C / GEN_TO_HOURS  →  r_C = r_A * (1 + s_C/(D*GEN_TO_HOURS))
    r_C = r_A * (1 + s_C / (D * GEN_TO_HOURS))
    r_B = r_A * (1 + s_B / (D * GEN_TO_HOURS))
    # Per-hour mutation rate: delta_per_hr = delta_per_gen / GEN_TO_HOURS
    delta_C = 10**log_delta_C / GEN_TO_HOURS
    delta_B = 10**log_delta_B / GEN_TO_HOURS

    S_ss = D * k / (r_A - D)
    X_ss = Y * (S0 - S_ss)

    def odes(y, t):
        X_A, X_C, X_B, S = y
        S   = max(S,   1e-12)
        X_A = max(X_A, 0.0); X_C = max(X_C, 0.0); X_B = max(X_B, 0.0)
        mu_A = r_A * S / (S + k)
        mu_C = r_C * S / (S + k)
        mu_B = r_B * S / (S + k)
        dX_A = X_A * (mu_A - D) - (delta_C + delta_B) * X_A
        dX_C = X_C * (mu_C - D) + delta_C * X_A
        dX_B = X_B * (mu_B - D) + delta_B * X_A
        dS   = D * (S0 - S) - (X_A * mu_A + X_C * mu_C + X_B * mu_B) / Y
        return [dX_A, dX_C, dX_B, dS]

    t_grid = np.linspace(0, t_max, n_points)
    sol    = np.clip(odeint(odes, [X_ss, 0.0, 0.0, S_ss], t_grid), 0, None)
    X_tot  = sol[:, :3].sum(axis=1, keepdims=True)
    freqs  = sol[:, :3] / np.where(X_tot > 0, X_tot, 1)
    return t_grid, freqs

Translating the ODE to WF language — and why it matters for inference

The ODE and WF share the same parameters (Fig below). The translation is:

ODE parameter WF parameter Relationship
rC (max growth rate of CNV) sC (selection coefficient) sC=(rC−rA)/(rAln2)
δChr (per-hour mutation rate) δCgen (per-generation) δCgen=δChr·ln2/D
Continuous time t (hours) Discrete generation g g=t·D/ln2
Total cells =Xss×V Effective population size N N=Y(S0−Sss)×V

Consequence: the Avecilla WF model IS the discrete-generation approximation of the ODE. The Lauer data is measured in generations, so the WF model directly matches the time axis.

For inferring the mutation rate from Lauer data:

Use WF_Avecilla with SBI — the posterior on log_delta_C is the per-generation CNV mutation rate. Convert to per-hour via δhr=10δC·D/ln2.

The ODE adds nutrient dynamics (S) which matter for mechanistic understanding of why selection coefficients have particular values — but for parameter inference from population-frequency data, the WF is sufficient and faster to simulate.

S_SNV  = 1e-3
M_SNV  = 1e-5
N_CHU  = int(3.3e8)


def WF_Chuong(log_s, log_m, log_p0, seed=None):
    """
    Chuong et al. 4-genotype Wright-Fisher simulator.

    Parameters (log₁₀ scale)
    ────────────────────────
    log_s   : log10(CNV fitness benefit s)
    log_m   : log10(CNV mutation rate δ, WT→CNV⁺)
    log_p0  : log10(initial CNV⁻ fraction φ)

    Returns: np.array length 12 — CNV⁺ frequency at GENERATIONS
    """
    s, m, p0 = 10 ** np.array([log_s, log_m, log_p0])

    if seed is not None:
        np.random.seed(seed)

    w = np.array([1.0, 1.0 + s, 1.0 + s, 1.0 + S_SNV])
    M = np.array([
        [1 - m - M_SNV,  0,  0,  0],
        [m,              1,  0,  0],
        [0,              0,  1,  0],
        [M_SNV,          0,  0,  1],
    ], dtype='float64')
    E = M @ np.diag(w)

    n    = np.zeros(4)
    n[0] = N_CHU * (1 - p0)
    n[2] = N_CHU * p0

    cnv_freq = []
    for _ in range(int(GENERATIONS.max()) + 1):
        cnv_freq.append(n[1] / N_CHU)
        p = E @ (n / N_CHU); p /= p.sum()
        n = np.random.multinomial(N_CHU, p).astype(float)

    return np.array(cnv_freq)[GENERATIONS]

def WF_De(log_s, log_m, log_p0, generation=generation_de, seed=None, N=int(1.9e6)):
    """
    De et al. 2-genotype WF (CNV reversion).
    Genotype 0 = CNV (common), genotype 1 = non-CNV revertant (rare, fitness 1+s).
    Returns: np.array — CNV frequency at each generation.
    """
    s, m, p0 = 10 ** np.array([log_s, log_m, log_p0])
    if seed is not None:
        np.random.seed(seed)

    E = np.array([[1 - m, 0], [m, 1]], dtype='float64') @ np.diag([1.0, 1.0 + s])

    n = np.array([N * (1 - p0), N * p0])
    cnv_freq = []
    for _ in range(int(generation.max()) + 1):
        cnv_freq.append(n[0] / N)
        p = E @ (n / N); p /= p.sum()
        n = np.random.multinomial(N, p).astype(float)

    return np.array(cnv_freq)[generation.astype(int)]

def zhou_model(mu_tri, mu_loh, w_tri, w_loh,
               p_0=[1, 0, 0], N_e=100_000, generations=100,
               ret_gens=None, noise=0):
    """
    Zhou et al. aneuploidy stability WF simulator.

    Three genotypes: Tri (aneuploid) → WT or LOH via chromosome loss.

    Parameters (inferred via SBI/ABC)
    ──────────────────────────────────
    mu_tri : log10(Tri → WT transition rate per generation)
    mu_loh : log10(Tri → LOH transition rate per generation)
    w_tri  : trisomic fitness (linear scale, typically <1 — deleterious)
    w_loh  : LOH genotype fitness (linear scale)

    Transition matrix (mutate, then select):
        G = S @ M
        M[0,0] = 1 - mu_tri - mu_loh  (Tri stays Tri)
        M[1,0] = mu_tri                (Tri → WT)
        M[2,0] = mu_loh                (Tri → LOH)
        S = diag(w_tri, 1, w_loh)

    Returns: np.ndarray shape (len(ret_gens), 3) — fractions [Tri, WT, LOH]
    """
    if ret_gens is None:
        ret_gens = list(10*ZHOU_PASSAGES)
    mu_tri = 10 ** mu_tri
    mu_loh = 10 ** mu_loh

    N = np.array(np.array(p_0) * N_e, dtype=int)
    S = np.diag([w_tri, 1.0, w_loh])
    M = np.array([[1 - mu_tri - mu_loh, 0, 0],
                  [mu_tri,               1, 0],
                  [mu_loh,               0, 1]])
    G = S @ M  # mutate then select

    p = [N / N.sum()]
    for _ in range(generations + 1):
        N_t = G @ N
        N_t = np.random.multinomial(N_e, N_t / N_t.sum()) / N_e
        p.append(N_t)
        N = np.array(N_t * N_e, dtype=int)

    ret = np.array(p)[ret_gens]
    if noise > 0:
        ret += np.random.normal(0, noise, ret.shape)
    return ret

print("✓ zhou_model defined")
print("  Inferred parameters: mu_tri (log10), mu_loh (log10), w_tri, w_loh")

def zhou_noisy_sims(theta, sigma, n=50):
    results = []
    for i in range(n):
        rng = np.random.default_rng(i)
        th  = {k: v + rng.normal(0, sigma.get(k, 0)) for k, v in theta.items()}

    return results

Fitting strategy: θ + Gaussian noise

Each simulation is fed with θi~𝒩(θcentral,σ), where σ represents between-replicate variation in biological parameters. This separates two sources of variation in the data:

  • Drift (within-replicate stochasticity): captured by the multinomial sampling
  • Parameter variation (between-replicate differences in CNV rates, fitness): captured by σ

The central θ and σ can be refined by matching the median and spread of simulations to the data. For systematic inference, use SBI — see SBI_tutorial.ipynb.
